## 团队怎么用

1. 同事填“FAQ 修改建议”，记录通用问题、适用范围、依据和建议答案。
2. 维护者归类、去重并整理为中英文问答，发起 PR。
3. Kelvin 查看差异、提出修改，决定是否合并。
4. 已审核答案再按公开范围发布到 Odoo 官网。

目前没有设置定时采集或官网 / Nextcloud 自动同步。原始客户资料继续保留在原系统，FAQ 仅引用受限链接或内部编号。

## 当前审核条件

默认分支 main 通过 PR 更新，要求内容负责人 Kelvin 审阅。规则状态以仓库设置为准。公开可读不代表任何人都能直接修改正式答案。

本次使用 Kelvin 账号创建样板 PR，不能自我 Approve。正式使用时由同事提交，Kelvin 审核；公开库的外部贡献者也可通过 fork 和 PR 提出修改。
