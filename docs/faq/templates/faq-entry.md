# 客户会怎么问？

## 答案

用可直接回答客户的语言说明结论、适用范围和下一步。

## 适用范围

产品 / 规格 / 控制方式 / 市场。无法确认的范围写“待核验”。

## 依据与待确认

- RFQ 或证据：有权限控制的链接或内部编号。
- 待确认：写明未知事实，不用猜测补全。

## 对应语言

填写同编号另一语言文件的相对链接。

状态只使用 draft / approved / retired。受众使用 internal / public_candidate。
审核人、审核日期和 approved 状态必须对应真实 PR 审核。
