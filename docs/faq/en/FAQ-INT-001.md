# FAQ-INT-001 · What additional information is needed for an overseas project?

> Draft for review. Not published to the website.

## Answer

Along with the model, specification, and quantity, please provide the destination country or region, site power requirements, installation method, intended smart-home platform, and any required certifications or documents. We will check the available configuration and documentation for the selected product before you rely on those details for the project.

## Scope

Custom lighting projects requiring overseas delivery. Requirements must be checked by product and market.

## Internal verification notes (not for public publication)

This is a draft inquiry checklist. It does not claim that every fixture has a particular certification or promise a voltage, frequency, dimming feature, or delivery time.
