# FAQ-COM-017 · 你们提供开发套件（DevKit）、SDK 或开放接口吗？我们想做二次开发或平台对接。

## 答案

可以先提供现售型号的样品用于评估。开发套件、接口文档、固件资料以及本地控制能力的具体范围，按目标型号和项目确认；需要新增功能时按定制开发单独评估。请告诉我们目标型号、要对接的平台（例如 Apple 家居、涂鸦、Home Assistant 或自研平台）、需要的接口形式和数量，我们据此确认可提供的资料和方案。

## 适用范围

适用于现售 Matter 产品线，含 Matter over Thread 与 Matter over Wi-Fi 版本；私人定制灯具、白标 App 与私有化部署另行按项目确认。本条不表示所有型号都提供开放 API，也不表示所有型号都能在不依赖厂商云的情况下运行。

## 依据与待确认

- 依据类别：近期多起客户询价中重复出现的开发与集成类问题；原始记录在受限系统中核验，不在本仓库保存。
- 待确认：现售型号中哪些可提供标准 DevKit 与接口文档；是否提供开放 API 及其授权条款；白标 App 与私有化部署的可提供范围。
- 本条为草稿，未经业务与技术支持确认，不得对外发布，也不得据此报价或承诺交期。
