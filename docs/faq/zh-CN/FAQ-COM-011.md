# FAQ-COM-011 · 你们能做哪些品类？

> 待审核草稿，尚未发布到官网。

## 答案

我们覆盖智能开关与场景面板、mmWave 人体存在传感器、窗帘与卷帘电机、VRF 空调接口、0/1–10V 调光模块，以及 Home Assistant 中枢与 Thread 边界路由，并可提供 ESP32 模组与开发套件。具体型号、控制方式与认证状态需按 SKU 确认，请提供需要的品类和目标数量，我们对应到型号后再给报价。

## 适用范围

上述已整理的产品线。不代表每个型号都同时具备全部协议、功能或认证。
