# FAQ-INT-001 · 海外项目询价还需要确认哪些信息？

> 待审核草稿，尚未发布到官网。

## 答案

除型号、规格和数量外，建议提供目标国家或地区、现场供电条件、安装方式、计划使用的智能家居平台，以及项目要求的认证或文件清单。我们会按指定产品与配置核对可提供的方案和资料。请先确认这些条件，再将某一型号的参数或认证用于项目。

## 适用范围

有海外交付需求的私人定制灯饰项目；不同产品和市场分别确认。

## 内部核验说明（不随答案对外发布）

这是询价资料清单草稿，不代表全部灯具均已取得某项认证，也不新增电压、频率、调光功能或交期承诺。
