# FAQ-COM-014 · 你们的 Matter 产品支持认证转移吗？

> 待审核草稿，尚未发布到官网。

## 答案

支持。我们可以把已认证产品的 Matter 认证转移到您的品牌名下，您用自有品牌销售已认证产品，不必从零做认证。费用按型号和转移范围核算，包含转移费、年费和后续维护责任，需要您提供目标型号与数量后书面确认。如果您希望使用自己的 Vendor ID 和 DAC，我们也可以配合评估。

## 适用范围

已完成 Matter 认证的型号。尚未认证的型号不适用认证转移。

## 依据与待确认（内部核验，不随答案对外发布）

- 依据：[来源与已确认业务规则](../sources/README.md)。
- 待确认：费用口径、按型号是否同价、多型号打包折扣、自持 Vendor ID 与使用我方 DAC 两种模式的报价方式均未定，公开答案中不得出现具体金额。另需确认 CSA 年费属第三方费用、不由我方收取。
