# FAQ-COM-018 · 你们接受区域代理或经销合作吗？

## 答案

我们按国家和产品品类评估区域代理、经销与安装服务合作，合作范围可包括设备销售、安装调试、售后与技术支持。是否开放合作及能否授予区域独家，需结合现有渠道安排逐案评估，并以双方书面确认为准。请提供公司背景、覆盖区域、现有客户群和首年目标数量，我们会安排负责该市场的同事对接。
